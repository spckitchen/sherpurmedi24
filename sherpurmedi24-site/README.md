# SherpurMedi24 — Phase 1 Demo

A mobile-first, bilingual (Bangla/English) static homepage prototype for a local pharmacy directory in Sylhet, Bangladesh.

## Files
- `index.html` — homepage structure
- `css/style.css` — responsive styling
- `js/app.js` — demo search and area filter
- `assets/sherpurmedi24-logo.jpg` — supplied brand logo

## Run locally
Open `index.html` in a browser. For a better local development experience, use VS Code with Live Server.

## Publish with GitHub Pages
1. Push/upload all files and folders to the repository root.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Important
This is a non-operational demo. Pharmacy cards are fictional sample data. There is no live medicine catalogue, medical advice, prescription handling, account system, order submission, payment, or delivery. Do not use it to collect real patient or customer information. A production service requires appropriate legal/regulatory review, secure authentication, server-side authorization, private data storage, and operational safeguards.
